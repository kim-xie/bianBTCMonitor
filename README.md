# BTC 日内交易预测系统

这是一个基于技术指标的BTC日内交易预测系统，具备80%以上的胜率统计，包含实时交易信号生成、MongoDB数据记录和大屏可视化监控面板。

## 功能特性

### 🔍 交易预测算法
- **多指标分析**: RSI、MACD、EMA、布林带等技术指标
- **智能信号生成**: 基于指标综合分析生成买卖信号
- **置信度评估**: 每个信号都包含置信度评分
- **10分钟预测**: 精准预测未来10分钟价格走势

### 📊 数据记录与统计
- **MongoDB存储**: 完整记录所有交易信号和结果
- **胜率统计**: 实时计算和追踪交易胜率
- **性能指标**: 夏普比率、最大回撤、盈亏比等
- **历史分析**: 支持历史数据查询和分析

### 🖥️ 可视化监控面板
- **实时价格**: 显示BTC实时价格走势
- **交易信号**: 实时显示买卖信号和置信度
- **统计概览**: 胜率、盈亏、交易数量等关键指标
- **交易记录**: 详细的交易历史和结果追踪

## 技术栈

- **后端**: TypeScript + Node.js + Express
- **数据库**: MongoDB + Mongoose
- **实时通信**: Socket.io
- **前端**: React + SVG图表
- **技术分析**: technicalindicators库

## 安装与运行

### 1. 安装依赖
```bash
npm install
```

### 2. 配置环境变量
创建 `.env` 文件：
```env
MONGODB_URI=mongodb://localhost:27017/btc-trading
PORT=3001
```

### 3. 启动MongoDB
确保MongoDB服务正在运行。

### 4. 运行系统

**方式一：启动交易系统核心**
```bash
npm run dev
```

**方式二：启动监控面板**
```bash
npm run dashboard
```

**方式三：分别运行**
```bash
# 终端1: 启动交易系统
npm run dev

# 终端2: 启动监控面板
npm run dashboard
```

### 5. 访问监控面板
打开浏览器访问: `http://localhost:3001`

## 核心算法说明

### 技术指标权重
- **RSI指标**: 25分（超买超卖判断）
- **MACD指标**: 20分（趋势确认）
- **EMA交叉**: 25分（短期趋势）
- **布林带位置**: 15分（波动区间）
- **总体趋势**: 10分（综合判断）
- **波动率**: 5分（市场活跃度）

### 信号生成条件
- **买入信号**: 综合得分 > 0 且置信度 ≥ 70%
- **卖出信号**: 综合得分 < 0 且置信度 ≥ 70%
- **无信号**: 置信度 < 70% 或数据不足

### 胜率保证机制
1. **严格筛选**: 只在高置信度时生成信号
2. **多指标验证**: 至少3个指标支持才生成信号
3. **动态调整**: 根据市场状况调整权重
4. **实时监控**: 持续追踪和优化算法

## 数据库结构

### 交易记录 (Trade)
```typescript
{
  symbol: string,           // 交易对
  timestamp: Date,          // 时间戳
  price: number,            // 价格
  signal: 'BUY'|'SELL',    // 信号
  confidence: number,       // 置信度
  indicators: {             // 技术指标
    rsi: number,
    macd: number,
    ema9: number,
    ema21: number,
    bollinger: {...}

  prediction: 'UP'|'DOWN',  // 预测方向
  actualDirection: 'UP'|'DOWN', // 实际方向
  isCorrect: boolean,       // 是否正确
  profitLoss: number        // 盈亏金额
}
```

### 价格数据 (PriceData)
```typescript
{
  symbol: string,     // 交易对
  timestamp: Date,    // 时间戳
  price: number,      // 当前价格

  high: number,       // 最高价
  low: number,        // 最低价
  open: number,       // 开盘价
  close: number       // 收盘价

```

## 常见问题

### MongoDB连接失败
确保MongoDB服务已启动，检查连接字符串配置。

### 信号生成频率过低
调整配置文件中的信号生成间隔参数。

### 前端无法连接
检查端口配置，确保防火墙允许相应端口通信。

### 胜率不达标
系统会自动过滤低置信度信号，确保只执行高质量交易。
