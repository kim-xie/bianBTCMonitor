# BTC 日内交易预测系统

这是一个基于技术指标的BTC日内交易预测系统，具备80%以上的胜率统计，包含实时交易信号生成、MongoDB数据记录和大屏可视化监控面板。

## 功能特性

### 🔍 交易预测算法
- **策略注册表**: 旧策略已全部下线。当前启用两条趋势做多，以及「涨势下跌，弱反弹，反包做空」
- **历史记录**: 仍可查询已经产生的交易和胜率
- **10分钟结算**: 已有持仓仍按 10 分钟到期结算

### 📊 数据记录与统计
- **MongoDB存储**: 完整记录所有交易信号和结果
- **胜率统计**: 实时计算和追踪交易胜率
- **性能指标**: 夏普比率、最大回撤、盈亏比等
- **历史分析**: 支持历史数据查询和分析

### 🖥️ 可视化监控面板
- **实时价格**: 显示BTC实时价格走势
- **交易信号**: 实时显示买卖信号和置信度
- **统计概览**: 胜率、盈亏、交易数量等关键指标
- **交易记录**: 详细的交易历史和结果追踪

## 技术栈

- **后端**: TypeScript + Node.js + Express
- **数据库**: MongoDB + Mongoose
- **实时通信**: Socket.io
- **前端**: React + SVG图表

## 安装与运行

### 1. 安装依赖
```bash
npm install
```

### 2. 配置环境变量
创建 `.env` 文件：
```env
MONGODB_URI=mongodb://localhost:27017/btc-trading
PORT=3001
```

### 3. 启动MongoDB
确保MongoDB服务正在运行。

### 4. 运行系统

**方式一：启动交易系统核心**
```bash
npm run dev
```

**方式二：启动监控面板**
```bash
npm run dashboard
```

**方式三：分别运行**
```bash
# 终端1: 启动交易系统
npm run dev

# 终端2: 启动监控面板
npm run dashboard
```

### 5. 访问监控面板
打开浏览器访问: `http://localhost:3001`

## 核心算法说明

旧策略已全部下线。策略只定义在 `src/strategies/registry.ts`。已经持仓的订单仍按 10 分钟到期结算。

趋势只看 EMA50。已收盘 5 分钟 K 线的收盘价在 EMA50 上方为多头趋势，在 EMA50 下方为空头趋势。收盘价等于 EMA50 时，既不是多头趋势，也不是空头趋势。

当前启用两条趋势做多，一条趋势做空。

「趋势策略：多次上穿反包做多」：最近 20 根已收盘 5 分钟 K 线里至少 2 次上穿 EMA50。最后一次上穿之后，到反包阳线之前的 K 线都收在 EMA50 上方 0.30% 以内，不要求根数。最后一根阳线收盘高于前一根阴线的开盘价，并且这根阳线本身也收在 EMA50 上方 0.30% 以内，收盘做多。

「趋势策略：强势上涨、弱回调反包做多」：最近 20 根里先连续至少 3 根强势阳线。强势阳线的实体至少是前面 10 根实体中位数的 2 倍，并且收盘高于前一根收盘。随后的弱回调里，每根实体不超过强势阳线平均实体的一半，收盘仍在 EMA50 上方，最低价不跌破这段涨幅的一半。阳线反包前一根阴线后立即做多。

「趋势策略：涨势下跌，弱反弹，反包做空」：最近 20 根里，价格先在 EMA50 上方，随后连续至少 2 根强势阴线。强势阴线的实体至少是前面 10 根实体中位数的 2 倍，并且收盘低于前一根收盘。随后的弱反弹里，每根实体不超过下跌阴线平均实体的一半，最高价不回到下跌前的高点。阴线反包前一根阳线，并且收盘落到 EMA50 下方，立即做空。

## 数据库结构

### 交易记录 (Trade)
```typescript
{
  symbol: string,           // 交易对
  timestamp: Date,          // 时间戳
  price: number,            // 价格
  signal: 'BUY'|'SELL',    // 信号
  confidence: number,       // 置信度
  prediction: 'UP'|'DOWN',  // 预测方向
  actualDirection: 'UP'|'DOWN', // 实际方向
  isCorrect: boolean,       // 是否正确
  profitLoss: number        // 盈亏金额
}
```

### 价格数据 (PriceData)
```typescript
{
  symbol: string,     // 交易对
  timestamp: Date,    // 时间戳
  price: number,      // 当前价格
  volume: number,     // 交易量
  high: number,       // 最高价
  low: number,        // 最低价
  open: number,       // 开盘价
  close: number       // 收盘价
}
```

## 常见问题

### MongoDB连接失败
确保MongoDB服务已启动，检查连接字符串配置。

### 信号生成频率过低
调整配置文件中的信号生成间隔参数。

### 前端无法连接
检查端口配置，确保防火墙允许相应端口通信。

### 不再产生新信号
技术指标移除后，系统不再开新仓。已有持仓仍会在到期后结算。
